# Viking Raiders

A free, ad-free phone puzzle game: send longships down the fjord to clear a wall of shields.
Every color has its own emblem, so it plays fine for color blind raiders. 1000 raids of growing difficulty.

Play it at the GitHub Pages link for this repository, then use your browser's "Add to Home Screen" to install it.
Progress is saved on the device and the game works offline after the first visit.
